# .github
Afford-X Inc

## Public site

This repository hosts a small, public-facing static site under [`docs/`](docs/index.html) that
introduces Afford-X — no GitHub sign-in required to view it. It summarizes the company's
exclusion-first advertising approach and the Affordability Language Model (ALM), with a link out
to [afford-x.com](https://afford-x.com) for the latest details.

To publish it with GitHub Pages:

1. Go to **Settings > Pages** for this repository.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Choose the `main` branch and the `/docs` folder, then save.
4. GitHub will publish the site at `https://afford-x.github.io/.github/` (or a configured custom domain).
